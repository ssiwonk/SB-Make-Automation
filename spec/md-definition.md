# md 파일 정의서 (1차 md → 2차 md 변환 규칙)

이 문서는 `source_to_md/` 변환기가 생성한 1차 md(`md/<원본파일명>_v1.md`)를
2차 md(`md/<원본파일명>_v2.md`)로 수정할 때 AI가 반드시 따라야 하는 규칙이다.

## 0. 대전제

- 1차 md의 본문 내용은 추가·요약·편집·삭제하지 않고 그대로 활용한다.
  (단, 아래 1~6 규칙에 해당하는 개발 지시어/서식/구분자 조정은 예외로 허용된다.)
- 대상 파일 최상단에는 항상 아래 marp frontmatter를 추가한다.

```
---
marp: true
theme: my-theme
---
```

  (`theme` 값은 예시 리터럴 `my-theme`을 그대로 사용하며, 필요 시 사용자가 추후 직접 수정한다.)

## 1. 헤더 위계 (h1~h4 이외의 헤더 금지)

- **h1(표지)**: 문서에 단 1개만 존재. 1차 md 최상단의 파일명 기반 가짜 제목
  (`# <원본파일명>`)과 `- Source:` / `- Total slides:` 같은 변환기 메타정보는
  삭제하고, 그 아래 실제 표지 콘텐츠(과목명·주차·발표자 등)를 h1으로 사용한다.
- **h2(간지)**: 대단원 전환 지점에만 사용한다.
  - pptx 계열(유닛/페이지/슬라이드 구조): "유닛" 제목을 h2로 사용하며,
    같은 유닛 안에서는 반복하지 않고 유닛이 바뀔 때 1회만 등장한다.
    "형성평가/학습정리/추가 학습요소"처럼 유닛 라벨이 없는 독립 섹션은
    h2 없이 h3로만 처리한다(§1의 h3 규칙 참조).
  - 대본/차시 계열(차시 구조): "Ⅰ, Ⅱ, Ⅲ..." 차시 제목을 h2로 사용한다.
- **h3(슬라이드 제목)**:
  - pptx 계열: "페이지" 제목을 h3로 사용한다(= 슬라이드 제목).
  - 대본 계열: "▶ 슬라이드 N. 제목"의 제목 부분을 h3로 사용한다.
  - 유닛/차시 라벨이 없는 독립 섹션(형성평가, 학습정리, 추가 학습요소,
    강의 개요 등)의 제목도 h3로 취급한다.
- **h4(가버링 메시지)**:
  - pptx 계열: "슬라이드 N. 제목"의 제목 부분을 h4로 사용한다
    (즉 페이지 제목=h3, 슬라이드 제목=h4).
  - 대본 계열 및 독립 섹션: 자연스러운 가버링 문구가 원문에 없으므로,
    AI가 해당 h3 하위 본문 내용을 근거로 한 줄 요약을 새로 생성하여 h4로 넣는다.
    (이 경우에 한해 "본문 요약 생성"이 허용되며, 본문 자체는 그대로 둔다.)
- 이 4단계 외의 헤더 표시(`#####` 등, 원문의 임의 헤더 포함)는 절대 사용하지 않는다.
  그 외 모든 텍스트는 본문으로 취급한다.

## 2. h3-h4 동반 규칙

- h3 하위에 h4가 여러 개 있을 경우, 각 h4 위에 h3 제목을 동일하게 중복 표기한다.
  (h3 없이 h4만 단독으로 존재할 수 없다.)

## 3. 구분자 및 빈 줄 규칙

- h1, h2, h3 각 블록의 위/아래에는 빈 줄을 하나씩 두고 `---`를 삽입한다.
- h4는 h3와 한 블록으로 묶이므로 h4 자체에는 별도의 `---`를 붙이지 않는다
  (h3+h4+본문 전체가 하나의 슬라이드 블록이며, 이 블록의 끝에서 `---`로 구분).

## 4. 서식 삭제/치환 규칙

- 볼드체(`**...**`)와 기울임체(`*...*`, `_..._`) 마크업은 모두 제거한다
  (텍스트 내용은 유지, 서식 마크업만 제거).

## 5. 개발 용어/지시어 삭제 규칙

아래 항목은 라벨/지시문/자동 생성 텍스트/본문 속 단어 여부와 관계없이
모두 삭제하거나 자연스러운 표현으로 대체한다.

- "유닛N", "페이지N", "슬라이드 N." 등 개발 구조 라벨
- "▶ 슬라이드 N. 제목", 시간코드(`[00:00~01:00]` 등), `※ 화면 구성: ...` 연출 지시문
- 슬라이드 제목에 붙은 대괄호 태그: `[요약]`, `[영상]`, `[N주차]` 등 개발/편집 지시어
  (h4에는 순수한 제목 텍스트만 남긴다)
- 이미지 마크다운의 자동 생성 alt 텍스트(예: `![Slide 15 Image 15](경로)`)의
  "Slide"류 표현
- 본문 문장 속에 자연스럽게 등장하는 "유닛/슬라이드/페이지" 단어
  (예: "완료하면 다음 유닛으로" → 문맥에 맞게 삭제하거나 다른 표현으로 대체)

## 6. 변경 요약 보고

- 2차 md 저장 후, AI는 어떤 원칙을 어떻게 적용했는지(특히 h4 자동 생성 위치,
  삭제한 지시어 목록) 사용자에게 요약 보고한다.
