# pptx 제작 정의서 (Markdown → PPTX 디자인 및 제작 규칙)

이 문서는 최종 확정된 Markdown 원고(`md/<원본파일명>_v최종.md`)를 바탕으로 `ppt-master`를 활용하여 고품질 PPTX를 제작할 때 AI가 반드시 준수해야 하는 디자인, 타이포그래피, 레이아웃 및 기술적 구현 규칙이다.

---

## 1. 기본 규격 및 캔버스 설정 (동적 비율 분기)

- **16:9 와이드 규격 (`1280×720 px`, 13.333×7.5 inch) [노션 개발비율 '16:9' 시 기본]**:
  - root SVG: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1280 720" font-family="Malgun Gothic" lang="ko-KR">`
  - ppt-master 초기화: `--format ppt169`
  - 가용 너비: `1160px` (`x=60` ~ `x=1220`, 좌우 60px 안전 마진), 가용 높이: `y=160` ~ `y=680`
  - 사후 `convert-ratio.py` 실행 불필요 (네이티브 16:9 직접 완성)
- **4:3 표준 규격 (`1024×768 px`, 10×7.5 inch) [노션 개발비율 '4:3' 시 기본]**:
  - root SVG: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1024 768" font-family="Malgun Gothic" lang="ko-KR">`
  - ppt-master 초기화: `--format ppt43`
  - 가용 너비: `904px` (`x=60` ~ `x=964`, 좌우 60px 안전 마진)
  - 4:3 빌드 완료 후 `scripts/convert-ratio.py`를 실행하여 와이드 변환본(`<파일명>-169.pptx`) 동시 생성 보관
- **슬라이드 역할 태그**:
  - 표지 슬라이드: `data-pptx-page-role="cover"`
  - 간지/섹션 슬라이드: `data-pptx-page-role="section"`
  - 일반 본문 슬라이드: `data-pptx-page-role="content"`

---

## 2. 사용자 지정 스타일 및 컬러 팔레트 적용 규칙

- **동적 스타일 적용**: 사용자는 슬라이드 제작 요청 시 매번 원하는 **디자인 스타일**, **주색상(Primary)**, **강조색상(Accent)**을 다르게 지정한다.
- **프롬프트 우선 원칙**: AI는 사용자가 프롬프트에서 제시한 스타일과 컬러 팔레트를 최우선으로 반영하여 슬라이드 배경, 카드 서피스, 다이어그램, 텍스트 포인트를 동적으로 구성한다. 특정 고정 테마를 강제하지 않는다.

---

## 3. 타이포그래피 및 폰트 크기 환산 규칙

PPT 포인트(pt)와 SVG 픽셀(px)은 96 DPI 기준으로 `1pt = 1.3333px`의 환산비를 가진다 (`px = pt × 4 / 3`, `pt = px × 0.75`).

| 위계 | 원고 요소 | PPT 기준 (pt) | SVG 렌더링 규격 (px) | 비고 |
|---|---|---|---|---|
| **h1** | 표지 대제목 | 42pt 이상 | **`56px` ~ `64px`** | bold, 지정 텍스트 기본색 |
| **h2** | 간지/단원 제목 | 32pt 이상 | **`42px` ~ `48px`** | bold, 중앙 정렬 |
| **h3** | 슬라이드 대제목 | 32pt | **`42.67px` ~ `43px`** | bold, 지정 텍스트 기본색 |
| **h4** | 소제목 (가버링 메시지) | 24pt | **`32px`** | semi-bold, 지정 주색상/포인트색<br>*(긴 제목 2줄 분할 시 최소 `28px` 허용)* |
| **본문** | 카드 본문/설명 텍스트 | 16pt 이상 | **최소 `21.33px` ~ `22px`** | 가독성 높은 본문 텍스트 기본색 |
| **라벨/캡션** | 다이어그램 내부 라벨/캡션 | 14pt 이상 | **최소 `18.67px` ~ `19px`** | 다이어그램 내부 짧은 텍스트에 한함 |

## 4. 텍스트 무결성 및 임의 요소 배제 원칙

- **헤더 텍스트 100% 보존**:
  - 원고의 `h1`, `h2`, `h3`, `h4` 텍스트는 **토씨 하나 바꾸지 않고 원문 그대로** 적용한다.
  - 가로 폭이 넘칠 경우 글자를 임의로 삭제하거나 줄이지 말고, 반드시 `<tspan dy="...">`로 줄바꿈하여 원문을 온전히 보존한다.
- **원고 내용 임의 추가 금지**:
  - 원고에 없는 새로운 문장, 임의의 설명, 사견 등을 추가하지 않는다.
  - *(단, 시각화를 위한 순서 번호(1, 2, 3), 화살표, 범례, 아이콘 라벨 등 순수 구조적 장치는 적극 허용)*
- **불필요한 임의 텍스트 배제**:
  - 원고에 없는 **키커(kicker), 페이지 번호, 임의 슬라이드 번호(예: `01 / 34`), 임의 푸터 텍스트는 일체 넣지 않는다.**

## 5. 인포그래픽 중심 시각화 (슬라이드의 70% 이상)

단순 줄글 나열을 엄격히 지양하고, **슬라이드 면적의 70% 이상을 다이어그램과 구조화된 인포그래픽**으로 구성한다.

- **권장 인포그래픽 패턴**:
  1. **원형 플라이휠 / 도넛 링**: 핵심 이념, 유기적 상호작용, 순환 구조
  2. **수평/수직 프로세스 체인 (셰브론/파이프라인)**: 연간 일정, 단계별 추진 절차, 시계열 연혁
  3. **다층 플랫폼 스택 / 피라미드**: 법체계 위계, 상·하위 법령 구조, 추진 인프라 계층
  4. **3축 트라이앵글 / 대칭형 밸런스 카드**: 3대 핵심 주체, 권리-책임 대칭, 법률-시행령 연계
  5. **매트릭스 타일 그리드 (2×2, 2×3, 4×2)**: 다분야 병렬 시책, 8대 실태조사 영역, 6대 국가 책무
  6. **중앙-지방 분기 네트워크 트리**: 중앙조정위 ↔ 지방조정위 이원화 체계, 위임·위탁 전달체계

## 6. 도형 이탈 방지 및 슬라이드 분할 (Split) 규칙

- **도형 이탈 방지 (Overflow Prevention)**:
  - 텍스트가 카드나 배지 밖으로 벗어나지 않도록 글자 수 기준 안전 폭을 사전에 계산한다.
  - 한글 폰트 기준 `body(22px)`는 약 4.3자/100px이므로, 너비 800px 박스에는 한 줄에 34자 이내로 배치하거나 여러 줄로 나눈다.
  - 캔버스 너비(1024px) 내 안전 영역: 좌우 60px 마진 유지 (`x=60` ~ `x=964`, 가용 너비 `904px`).
- **슬라이드 분할 (Split) 규칙**:
  - 한 슬라이드에 담아야 할 원고의 내용(법률 조문, 사례, 토론, 용어 등)이 많아 도형 이탈이나 가독성 저하가 우려되는 경우,
  - **동일한 `h3`과 `h4` 제목을 그대로 유지한 채 슬라이드를 2장 이상으로 분할(Split)**하여 제작한다. (예: `청년의 정의와 주요 용어` ①연령/사례, ②6대 핵심용어)

## 7. SVG 계층 구조 및 ppt-master 품질 검사(Quality Checker) 통과 규격

`svg_quality_checker.py --canonical-authoring --stage final` 검사를 무결점(0 Errors)으로 통과하기 위해 아래의 SVG 구조를 반드시 준수한다.

### 표준 슬라이드 템플릿 구조
```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1024 768" font-family="Malgun Gothic" lang="ko-KR" data-pptx-page-role="content">
  <!-- 1. 배경 (id="slide-bg"와 data-pptx-role="background" 필수, fill은 사용자 지정 배경색) -->
  <rect id="slide-bg" width="1024" height="768" fill="{지정_배경색}" data-pptx-role="background"/>

  <!-- 2. 헤더 그룹 (data-pptx-bounds 필수 지정) -->
  <g id="header-group" data-pptx-bounds="60 30 904 125">
    <text x="60" y="70" font-size="43" font-weight="700" fill="{지정_텍스트_기본색}">{h3 제목}</text>
    <text x="60" y="115" font-size="32" font-weight="600" fill="{지정_주색상_또는_포인트색}">{h4 가버링 소제목}</text>
    <rect x="60" y="142" width="904" height="2" fill="{지정_구분선_색상}"/>
  </g>

  <!-- 3. 메인 콘텐츠 그룹 (data-pptx-bounds 필수 지정, 모든 본문 카드/도형을 이 안에 배치) -->
  <g id="content-group" data-pptx-bounds="60 160 904 550">
    <!-- 인포그래픽 카드, 다이어그램, 텍스트 요소들 (사용자 지정 스타일 및 컬러 적용) -->
  </g>
</svg>
```

### 필수 준수 기술 사항
1. **Root `<g>` 바운즈 필수**: `<svg>` 바로 아래의 모든 `<g>`는 반드시 `data-pptx-bounds="x y w h"` 속성을 포함해야 한다.
2. **배경 객체 ID**: 배경 `<rect>`에 `data-pptx-role="background"`를 줄 때는 반드시 `id="slide-bg"` 등 고유 ID를 부여한다.
3. **XML 특수문자 이스케이프**: 본문 텍스트 내 `&`는 `&amp;`, `<`는 `&lt;`, `>`는 `&gt;`로 완벽하게 치환한다.
4. **긴 텍스트 tspan 처리**: `h4`가 28자 이상인 경우 `<tspan x="60" dy="34">`를 활용해 2줄로 배치하여 가로 1024px 범위를 초과하지 않도록 한다.

## 8. 이미지 처리 규칙

- **이미지 포함 원고**: 원고 Markdown에 이미지(`![...](경로)`)가 포함되어 있다면, 해당 이미지를 슬라이드 레이아웃(좌측 이미지 + 우측 인포그래픽 구조 등)에 반드시 1:1로 반영한다.
- **텍스트 전용 원고**: 원고에 이미지가 없는 경우 임의의 외부 사진을 억지로 채우지 않고, 세련된 네이티브 인포그래픽 도형(카드, 링, 셰브론, 스택)으로 완성도를 높인다.
